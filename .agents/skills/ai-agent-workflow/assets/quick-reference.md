# AI智能体5级用法 - 快速参考卡

## 📋 任务级别选择

| 级别 | 复杂度 | 适用场景 | 示例 |
|------|--------|----------|------|
| **第1级** | 低 | 快速原型、小功能 | 编写函数、代码片段 |
| **第2级** | 中 | 项目维护、Bug修复 | 重构代码、修复问题 |
| **第3级** | 中高 | 功能模块开发 | API接口、数据库操作 |
| **第4级** | 高 | 架构设计、系统优化 | 系统重构、性能优化 |
| **第5级** | 极高 | 端到端功能交付 | 完整项目开发 |

## 🔄 核心工作流程

### 1️⃣ 明确任务描述
```
✅ 好的描述：
"用Python Flask实现用户注册接口，要求：
- 用户名：3-20字符，字母开头
- 密码：8-20字符，包含大小写和数字
- 邮箱验证格式
- 返回JWT token"

❌ 不好的描述：
"写一个注册功能"
```

### 2️⃣ 提供上下文
```
📋 必要上下文：
- 现有代码片段
- 项目结构说明
- 技术栈信息
- 业务规则
- 数据格式
```

### 3️⃣ 分阶段执行
```
执行顺序：
1. 核心功能实现
   ↓
2. 错误处理完善
   ↓
3. 边界条件处理
   ↓
4. 性能优化
   ↓
5. 代码美化
```

### 4️⃣ 验证结果
```
验证清单：
□ 代码逻辑正确
□ 命名规范清晰
□ 错误处理完善
□ 性能符合要求
□ 安全漏洞检查
```

### 5️⃣ 迭代优化
```
优化方向：
- 提示词更精确
- 上下文更完整
- 约束条件更明确
- 验收标准更具体
```

```
❌ "写一个函数"
✅ "用Python编写一个异步HTTP请求函数，使用aiohttp库"

❌ "优化代码"
✅ "优化这段SQL查询，当前响应时间>500ms，目标<100ms"

✅ "实现JWT登录接口，支持邮箱+密码登录，返回access_token和refresh_token"
```

## ⚠️ 常见错误

### 1. 描述过于模糊
```
❌ "写一个函数"
✅ "用Python编写一个计算斐波那契数列的函数，输入n返回前n项"
```

### 2. 缺少边界条件
```
❌ "计算列表平均值"
✅ "计算列表平均值，空列表返回0.0"
```

### 3. 没有指定技术栈
```
❌ "写一个HTTP请求"
✅ "用Python的requests库发送GET请求"
```

### 4. 忽略测试
```
❌ "只修改代码"
✅ "修改代码并更新对应的测试用例"
```

# Codex 工作流辅助脚本

本目录包含使用Codex工作流时的辅助脚本和工具。

## 目录结构

```
scripts/
├── templates/           # 提示词模板
├── checklists/          # 检查清单
└── tools/              # 辅助工具
```

## 快速开始

### 1. 选择合适的级别

根据任务复杂度选择使用级别：

| 级别 | 适用场景 | 复杂度 |
|------|----------|--------|
| 第1级 | 快速原型、小功能 | 低 |
| 第2级 | 项目维护、Bug修复 | 中 |
| 第3级 | 功能模块开发 | 中高 |
| 第4级 | 架构设计、系统优化 | 高 |
| 第5级 | 端到端功能交付 | 极高 |

### 2. 使用模板

根据任务类型选择对应的模板：

- `new-feature.md` - 新功能开发模板
- `bug-fix.md` - Bug修复模板
- `refactor.md` - 代码重构模板
- `architecture.md` - 架构设计模板

### 3. 验证结果

使用检查清单验证生成的代码：

- `code-review.md` - 代码审查清单
- `testing.md` - 测试验证清单
- `security.md` - 安全检查清单

## 最佳实践

### 1. 提示词优化

**好的提示词：**
```
任务：实现用户注册功能

需求描述：
- 用户名：3-20个字符，字母开头，只能包含字母、数字、下划线
- 密码：8-20个字符，必须包含大小写字母和数字
- 邮箱：有效邮箱格式

技术要求：
- 使用Python Flask框架
- 使用SQLAlchemy ORM
- 密码使用bcrypt加密

验收标准：
1. 注册成功返回用户信息
2. 用户名重复返回错误提示
3. 密码强度不符合返回错误提示
4. 邮箱格式错误返回错误提示
```

**不好的提示词：**
```
写一个注册功能
```

### 2. 任务分解

**大型任务分解：**
```
用户管理系统
├── 用户模块
│   ├── 注册功能
│   ├── 登录功能
│   ├── 个人信息管理
│   └── 密码修改
├── 权限模块
│   ├── 角色管理
│   ├── 权限分配
│   └── 权限验证
└── 日志模块
    ├── 操作日志
    ├── 登录日志
    └── 日志查询
```

### 3. 质量控制

## 常见问题

### Q1：如何选择合适的级别？

**A：** 根据任务复杂度选择：
- 简单函数、代码片段 → 第1级
- 重构、Bug修复 → 第2级
- 功能模块开发 → 第3级
- 架构设计、系统优化 → 第4级
- 完整项目开发 → 第5级

### Q2：如何提高生成质量？

**A：** 
1. 提供清晰的需求描述
2. 给出完整的上下文
3. 明确技术约束
4. 指定验收标准

### Q3：如何处理复杂任务？

**A：** 
1. 将大任务拆分为小任务
2. 按依赖关系排序
3. 逐个执行并验证
4. 最后进行集成测试

### Q4：如何确保代码安全？

**A：** 
1. 进行代码审查
2. 检查安全漏洞
3. 验证输入输出
4. 测试异常情况

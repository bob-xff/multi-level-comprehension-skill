# 代码审查检查清单

## 使用说明

本清单用于代码审查，帮助确保代码质量和一致性。请在代码审查时逐项检查。

---

## 一、代码质量

### 1.1 代码规范
- [ ] 遵循语言编码规范（PEP 8 / Airbnb Style Guide / 等）
- [ ] 变量命名清晰有意义
- [ ] 函数命名准确描述功能
- [ ] 类命名符合业务含义
- [ ] 常量使用全大写命名

### 1.2 代码结构
- [ ] 函数长度适中（< 50行）
- [ ] 类职责单一
- [ ] 模块划分合理
- [ ] 代码层次清晰
- [ ] 避免过度嵌套

### 1.3 代码可读性
- [ ] 注释清晰准确
- [ ] 复杂逻辑有说明
- [ ] 函数有文档字符串
- [ ] 代码逻辑易于理解
- [ ] 无魔法数字/字符串

## 使用示例

### 代码审查流程

1. **准备阶段**
   - 阅读需求文档
   - 了解业务背景
   - 熟悉相关代码

2. **审查阶段**
   - 逐项检查清单
   - 记录问题点
   - 提出改进建议

3. **反馈阶段**
   - 汇总问题
   - 优先级排序
   - 与开发者沟通

4. **跟进阶段**
   - 验证修复
   - 确认改进
   - 更新清单

### 问题分类

**严重问题（必须修复）：**
- 安全漏洞
- 数据丢失风险
- 性能严重问题
- 功能错误

**重要问题（建议修复）：**
- 代码规范问题
- 可维护性问题
- 性能优化点
- 文档缺失

**一般问题（可选修复）：**
- 代码风格
- 命名优化
- 注释完善
- 小的优化点

# 质量指标体系

本文件定义AI智能体5级用法工作流的质量指标体系，用于度量和评估使用效果。

## 一、核心指标

### 1.1 效率指标

| 指标名称 | 定义 | 计算公式 | 目标值 | 数据来源 |
|----------|------|----------|--------|----------|
| **任务完成率** | 成功完成的任务占比 | (完成任务数/总任务数) × 100% | ≥ 95% | 任务记录 |
| **平均响应时间** | 从开始到完成的平均时间 | 总耗时/任务数 | ≤ 30分钟 | 时间记录 |
| **一次成功率** | 首次执行即成功的占比 | (一次成功数/总任务数) × 100% | ≥ 80% | 测试结果 |
| **迭代次数** | 平均每个任务的迭代次数 | 总迭代次数/任务数 | ≤ 3次 | 迭代记录 |

### 1.2 质量指标

| 指标名称 | 定义 | 计算公式 | 目标值 | 数据来源 |
|----------|------|----------|--------|----------|
| **代码质量评分** | 代码审查的平均得分 | 总分/审查次数 | ≥ 8/10 | 代码审查 |
| **测试覆盖率** | 测试用例的覆盖率 | (覆盖行数/总行数) × 100% | ≥ 80% | 测试报告 |
| **缺陷密度** | 每千行代码的缺陷数 | (缺陷数/代码行数) × 1000 | ≤ 5个/KLOC | 缺陷记录 |
| **安全漏洞数** | 发现的安全漏洞数量 | 统计数量 | 0个 | 安全扫描 |

### 1.3 满意度指标

| 指标名称 | 定义 | 计算公式 | 目标值 | 数据来源 |
|----------|------|----------|--------|----------|
| **用户满意度** | 用户对结果的满意程度 | 平均评分(1-10) | ≥ 8分 | 用户反馈 |
| **代码接受率** | 代码被直接接受的占比 | (接受数/生成数) × 100% | ≥ 70% | 使用记录 |
| **复用率** | 代码被复用的占比 | (复用数/生成数) × 100% | ≥ 50% | 使用记录 |

## 四、指标采集方法

### 4.1 自动采集

```python
# 自动化指标采集示例
class MetricsCollector:
    """指标采集器"""
    
    def __init__(self):
        self.tasks = []
        self.metrics = {}
    
    def record_task(self, task_info):
        """记录任务信息"""
        self.tasks.append({
            "id": task_info["id"],
            "start_time": task_info["start_time"],
            "end_time": task_info["end_time"],
            "status": task_info["status"],
            "iterations": task_info.get("iterations", 0),
            "tool_used": task_info.get("tool_used", ""),
            "quality_score": task_info.get("quality_score", 0)
        })
    
    def calculate_metrics(self):
        """计算指标"""
        if not self.tasks:
            return {}
        
        completed_tasks = [t for t in self.tasks if t["status"] == "completed"]
        
        self.metrics = {
            "completion_rate": len(completed_tasks) / len(self.tasks) * 100,
            "avg_response_time": sum(t["end_time"] - t["start_time"] for t in completed_tasks) / len(completed_tasks),
            "avg_iterations": sum(t["iterations"] for t in completed_tasks) / len(completed_tasks),
            "avg_quality_score": sum(t["quality_score"] for t in completed_tasks) / len(completed_tasks)
        }
        
        return self.metrics
    
    def generate_report(self):
        """生成报告"""
        metrics = self.calculate_metrics()
        
        report = f"""
        AI智能体使用效率报告
        ====================
        
        任务完成率: {metrics.get('completion_rate', 0):.1f}%
        平均响应时间: {metrics.get('avg_response_time', 0):.1f}秒
        平均迭代次数: {metrics.get('avg_iterations', 0):.1f}次
        平均质量评分: {metrics.get('avg_quality_score', 0):.1f}/10
        """
        
        return report
```

## 五、指标分析

### 5.1 趋势分析

```python
# 趋势分析示例
def analyze_trends(metrics_history):
    """分析指标趋势"""
    
    trends = {}
    
    # 计算趋势
    for metric_name, values in metrics_history.items():
        if len(values) < 2:
            continue
        
        # 计算变化趋势
        recent_avg = sum(values[-3:]) / min(3, len(values))
        earlier_avg = sum(values[:-3]) / max(1, len(values) - 3) if len(values) > 3 else values[0]
        
        if recent_avg > earlier_avg * 1.1:
            trend = "↑ 上升"
        elif recent_avg < earlier_avg * 0.9:
            trend = "↓ 下降"
        else:
            trend = "→ 稳定"
        
        trends[metric_name] = {
            "current": recent_avg,
            "previous": earlier_avg,
            "trend": trend,
            "change": (recent_avg - earlier_avg) / earlier_avg * 100
        }
    
    return trends
```

### 5.2 根因分析

```python
# 根因分析示例
def root_cause_analysis(failure_cases):
    """失败案例根因分析"""
    
    causes = {
        "提示词不清晰": 0,
        "上下文不足": 0,
        "工具选择不当": 0,
        "需求不明确": 0,
        "技术约束冲突": 0
    }
    
    for case in failure_cases:
        if "描述模糊" in case.get("issues", []):
            causes["提示词不清晰"] += 1
        if "缺少代码" in case.get("issues", []):
            causes["上下文不足"] += 1
        if "工具不匹配" in case.get("issues", []):
            causes["工具选择不当"] += 1
        if "需求变更" in case.get("issues", []):
            causes["需求不明确"] += 1
        if "约束冲突" in case.get("issues", []):
            causes["技术约束冲突"] += 1
    
    return causes
```

## 六、改进机制

### 6.1 PDCA循环

```
Plan (计划)
  ↓
  设定目标
  制定计划
  分配资源
  ↓
Do (执行)
  ↓
  执行计划
  记录数据
  收集反馈
  ↓
Check (检查)
  ↓
  分析指标
  识别问题
  找出差距
  ↓
Act (改进)
  ↓
  制定改进措施
  实施改进
  验证效果
  ↓
  循环优化
```

### 6.2 持续改进流程

```
1. 数据收集
   ↓
   自动采集 + 手动反馈
   ↓
2. 指标计算
   ↓
   计算各项指标
   ↓
3. 问题识别
   ↓
   对比目标值
   识别差距
   ↓
4. 根因分析
   ↓
   分析问题原因
   找出根本原因
   ↓
5. 改进措施
   ↓
   制定改进方案
   实施改进
   ↓
6. 效果验证
   ↓
   验证改进效果
   确认达标
   ↓
7. 标准化
   ↓
   固化改进成果

```

## 版本说明

### 语义化版本控制

本项目遵循语义化版本控制规范：

- **主版本号 (MAJOR)**：当你做了不兼容的 API 修改
- **次版本号 (MINOR)**：当你做了向下兼容的功能性新增
- **修订号 (PATCH)**：当你做了向下兼容的问题修正

### 变更类型

- ✨ **新增 (Added)**：新功能
- ♻️ **变更 (Changed)**：现有功能的变更
- 🗑️ **弃用 (Deprecated)**：即将移除的功能
- 🗑️ **移除 (Removed)**：已移除的功能
- 🐛 **修复 (Bug Fixes)**：错误修复
- 🔒 **安全 (Security)**：安全相关变更
